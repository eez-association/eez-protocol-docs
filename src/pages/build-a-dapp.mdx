# Build a dApp

With EEZ, your contract calls a contract on another chain through a cross-chain proxy and uses the answer in the same transaction. These are the fastest ways to try it.

- **[Quickstarts](https://build.eez.io):** walkthroughs that show each call pattern step by step.
- **[RollupX dashboard](https://rollupx.eez.dev/dashboard):** deploy proxies, execute cross-chain calls and follow execution across L1 and L2.
- **[Remix plugin](https://app.remix.live?eez=true):** try cross-chain calls from the Remix browser IDE, using its EEZ tab (alpha).
- **[EVMcrispr](https://next-docs.evmcrispr.com/guides/eez/):** script atomic cross-chain calls and state reads between L1 and an L2 with the `eez` module.
- **[Build with AI](/build-with-ai):** give your coding agent these docs.
- **[Caveats](https://github.com/eez-association/eez-core-protocol/blob/main/docs/CAVEATS.md):** read these in the protocol spec before you ship.

To see what happens under the hood, follow one call in the [walkthrough](/eez-walkthrough).
